Syntax Tokens Reference
Interfaces Syntax Token

Defines Method Contracts Implemented By Classes. In Java, Types Like Runnable, Serializable, And Event Are Interfaces Rather Than Standard Classes. Styling Interfaces Separately Helps API Contracts Stand Out Instantly.

implements Runnable, Serializable, Event Scope: entity.name.type.interface
Keywords Syntax Token

Reserved Language Keywords Governing Program Control Flow, Declarations, Access Modifiers, And Language Grammar Rules.

public class ThemeService return true; Scope: keyword, storage.type
Types & Classes Syntax Token

Standard Object Types, Concrete Class Definitions, Built-In Framework Classes, And Complex Type References.

String, System, ArrayList, BaseService Scope: entity.name.type, support.class
Functions & Methods Syntax Token

Callable Routines, Member Methods, Function Invocations, And Function Declarations.

System.out.println("..."), run(), processTheme(...) Scope: entity.name.function
Variables Syntax Token

Local Variable Identifiers Declared Inside Method Bodies And Blocks.

List<String> tokens; boolean isFirst; int i = 0; Scope: variable, variable.other
Parameters Syntax Token

Named Arguments Passed Into Method Signatures, Constructors, And Lambda Expressions.

void processTheme(String themeId, int maxRetries) Scope: variable.parameter
Properties & Fields Syntax Token

Class Field Members, Static Constants, And Object Attributes Accessed Via Dot Syntax.

System.out, this.activeCount, THEME_NAME Scope: variable.other.property
Strings Syntax Token

Literal Text Data Enclosed In Double Quotes, Single Quotes, Or Template String Literals.

"InsynVsTheme", "Starting Theme Service" Scope: string, string.quoted
Escape Characters Syntax Token

Backslash-Prefixed Control Codes Nested Inside String Literals (E.g. Newlines, Tabs, Escaped Quotes).

"Line One\n\t\"Escaped Text\"" Scope: constant.character.escape
Numbers Syntax Token

Numeric Literal Values Including Integer Values, Floating Point Decimals, And Hexadecimal Numbers.

42, 2.5, 3.1415, 0xFF00AA Scope: constant.numeric
Booleans & Null Syntax Token

Truth Value Flags (True, False) And Special Empty State Language Primitives (Null, Undefined).

boolean isReady = true; if (data == null) Scope: constant.language.boolean
Regular Expressions Syntax Token

RegExp Pattern Matching Literals Delimited By Slashes In JavaScript And TypeScript.

const versionCheck = /^v\d+\.\d+\.\d+$/i; Scope: string.regexp
Comments Syntax Token

Single-Line And Multi-Line Developer Notes And Disabled Code Ignored During Compilation.

// Line Comment, /* Block Comment */ Scope: comment, punctuation.definition.comment
Doc Comments Syntax Token

Structured Documentation Blocks For Javadoc, TSDoc, And JSDoc Containing Metadata Tags Like @param And @return.

/** Executes Background Worker. @param workerName */ Scope: comment.block.documentation
Annotations Syntax Token

Compiler Directives And Metadata Decorators Applied To Classes, Methods, And Fields.

@Override, @Deprecated, @SuppressWarnings Scope: entity.name.type.annotation
Operators Syntax Token

Mathematical, Comparison, Assignment, And Logical Symbols Connecting Expressions.

==, !=, +, -, &&, ||, >= Scope: keyword.operator
Punctuation Syntax Token

Statement Terminators, Argument Delimiters, And Structural Separators In Code.

; (Semicolon), , (Comma), . (Dot), : (Colon) Scope: punctuation, meta.delimiter
Rainbow Brackets (Levels 1 - 3) Syntax Token

Alternating Colored Enclosures For Nested Braces, Parentheses, And Brackets Providing Clear Visual Nesting Depth.

{ ( [ Level 3 ] ) } Key: editorBracketHighlight.foreground1..3
